# 本地生产部署说明

**项目唯一根目录：`D:\grokdemo`**  
所有源码、文章、脚本、环境变量模板都在此目录内，不要写到别的盘或用户目录。

## 1. 进入项目

```powershell
cd D:\grokdemo
```

## 2. 环境变量（项目内）

```powershell
# 若还没有 .env.local，从模板复制（仍在 D:\grokdemo 内）
copy .env.example .env.local
```

## 3. 安装依赖（首次）

```powershell
npm install
```

## 4. 本地生产部署

```powershell
# 推荐：构建 + 启动
npm run prod

# 或使用脚本（自动释放 3000 端口）
npm run deploy:local

# 已构建过，只启动
npm run start
```

浏览器打开：http://localhost:3000

## 5. 日常开发（热更新）

```powershell
npm run dev
```

## 6. 写文章（生产模式下）

打开 http://localhost:3000/write  
密钥填写 `.env.local` 中的 `POST_WRITE_SECRET`（默认示例：`local-dev-secret`）  
文章会保存到 **`D:\grokdemo\content\posts\`**。

## 目录约定（均在项目内）

| 路径 | 内容 |
|------|------|
| `src/` | 全部前端与 API 源码 |
| `content/posts/` | Markdown 文章 |
| `public/` | 静态资源、封面、头像 |
| `scripts/` | 本地部署脚本 |
| `docs/` | 项目文档 |
| `.env.example` | 环境变量模板 |
| `.env.local` | 本地密钥（不提交） |
